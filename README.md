## Overview

Rustium is an independent browser-engine project exploring how modern browser infrastructure can be built with Rust.

The project prioritizes predictable memory usage, memory safety, a minimal attack surface, and a modular architecture.

Rustium is developed independently and is not a fork of Chromium, WebKit, or Gecko.

## Design Goals

- **Memory efficiency** — Keep memory usage low and predictable.
- **Security** — Leverage Rust's memory-safety guarantees and minimize attack surface.
- **Modularity** — Maintain clear boundaries between engine components.
- **Compatibility** — Progress toward practical support for modern web standards.
- **Maintainability** — Favor explicit interfaces and straightforward implementations.

## Project Status

Rustium is an active research and development project. Features, architecture, and compatibility are subject to change.
